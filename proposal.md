# Ozymandius, King of Kings

## Repository
https://github.com/ChrysBishop/utd-angm2305-26s-Ozymandius-King-of-kings.git

## Description
This will be an interactive animation of the poem, Ozymandius.

## Features
- Buttons
   - The user will be using a mouse to progress the animation, they will be pressing buttons on the screen to progress the animation.
- Have images fade in/out
   - When the buttons are pressed, they will be transitioning from one scene to the next, whether it be fades to black or new scenes coming into view and covering up the last one.
- Implement audio.
   - Audio that is reciting the poem must line up with the words on screen.

## Challenges
- Implimenting mouse interactions on a screen.
- How to fade in/out images in pygame.
- Getting audio to the screen

## Outcomes
Ideal Outcome:
- Smooth transitions, audio lines up with text, recurring background animations.

Minimal Viable Outcome:
- Transitions are cut and dry, audio is present but not fully aligned, background animations not present.
